# spec.md 機能・仕様一覧

## 基本情報
- 作成日: 2024-11-27
- 分析対象: docs/specifications/spec.md
- 目的: プロトタイプとの差分抽出用

## 1. 技術スタック
- Ruby 3.4.0 + Rails 8.0.1
- Tailwind CSS
- PostgreSQL
- AWS Lightsail + Nginx
- OpenAI API (ChatGPT)
- Sidekiq
- Docker Desktop

## 2. ページ構成
### フロントエンド
- `/` - ポートフォリオトップ（縦スクロール型）
- `/my-story` - My Story詳細ページ
- `/blog` - ブログトップページ
- `/blog/:slug` - ブログ記事詳細ページ
- `/blog/category/:slug` - カテゴリ別記事一覧
- `/blog/category/:parent/:child` - サブカテゴリ別記事一覧
- `/blog/tag/:slug` - タグ別記事一覧

### 管理画面
- `/{管理画面パス}` - 管理ダッシュボード（デフォルト: admin）
- 各種管理機能ページ

## 3. ポートフォリオセクション（8セクション）
1. **ヘッダー・ナビゲーション**
   - 固定ヘッダー（スクロール時追従）
   - スムーススクロールナビゲーション
   - 検索ボックス

2. **ヒーローセクション**
   - キャッチコピー
   - メインビジュアル
   - CTAボタン

3. **Aboutセクション**
   - プロフィール情報
   - 経歴・スキルセット
   - 技術スタック

4. **Serviceセクション**
   - 提供可能なサービス（カード形式）
   - 料金プラン（あれば）

5. **My Storyセクション**
   - キャリア変遷の概要
   - 詳細ページへの誘導

6. **Worksセクション**
   - ポートフォリオ作品
   - プロジェクト詳細（モーダル表示）

7. **Blogセクション**
   - 最新記事3-5件
   - ブログページへの誘導

8. **Contactセクション**
   - お問い合わせフォーム
   - Slack Webhook連携
   - SNSリンク

9. **フッター**
   - サイトマップ
   - コピーライト

## 4. お問い合わせ・通知機能
### お問い合わせフォーム
- 入力項目: 名前、メールアドレス、件名、メッセージ
- バリデーション（必須項目、メール形式）
- スパム対策（reCAPTCHA連携）

### Slack連携
- 通知内容: お問い合わせ者情報、件名・メッセージ、受付日時、管理画面リンク
- 設定項目: Webhook URL、通知チャンネル、ON/OFF切り替え

## 5. コンテンツ管理（CMS）機能
### ポートフォリオ管理
- ヒーロー: タイトル、サブタイトル、背景画像、CTAボタン
- About: プロフィール文、スキルリスト、経歴
- Service: サービスカード（タイトル、説明、アイコン）
- My Story: 概要文、詳細ページリンク
- Works: プロジェクト（タイトル、説明、画像、URL）
- Blog: 表示記事数、カテゴリフィルター
- Contact: フォーム設定、受信メールアドレス、Slack Webhook URL

### 共通機能
- Markdownサポート
- リアルタイムプレビュー
- 下書き保存
- 公開/非公開設定
- リビジョン管理

## 6. ブログ機能
### 記事管理
- Markdown形式での記事作成
- WYSIWYGエディタ（オプション）
- 下書き/公開/予約投稿
- リビジョン管理

### カテゴリ・タグ
- 2階層カテゴリ構造
- 複数タグ付け
- カテゴリアイコン・カラー

### SEO設定
- カスタムURL（スラッグ）
- メタディスクリプション
- OGP個別設定

### エディタ拡張機能
- メディア埋め込み: URLペーストで自動カード化、oEmbed対応
- 画像管理: ドラッグ&ドロップアップロード、自動リサイズ・最適化、alt属性必須化
- コード表示: シンタックスハイライト、行番号表示、コピーボタン

### AI支援機能
- 記事要約の自動生成
- 関連キーワード提案
- SEOスコアチェック

## 7. メディアライブラリ
### 画像管理
- 一覧: グリッド/リスト表示、フィルタ・検索、使用状況確認
- 編集: 基本編集（クロップ、回転）、一括処理、メタデータ編集
- 最適化: 自動WebP変換、複数サイズ生成、遅延読み込み対応

## 8. 検索機能
### 検索対象
- ブログ記事（タイトル、本文）
- カテゴリ・タグ
- ポートフォリオコンテンツ

### 検索仕様
- 全文検索（PostgreSQL）
- 日本語対応
- インクリメンタルサーチ
- 検索履歴・サジェスト

## 9. SEO/AEO機能
### 自動最適化
- メタデータ: タイトルタグ最適化、ディスクリプション自動生成、OGP自動設定
- 構造化データ: JSON-LD自動生成、Schema.org対応、パンくずリスト
- 技術的SEO: XMLサイトマップ、robots.txt、canonical設定

### AEO対応
- セマンティックHTML5
- 適切な見出し構造
- 画像alt属性
- AIフレンドリーなコンテンツ構造

## 10. 管理画面
### ダッシュボード
- アクセス統計サマリー
- 最近の投稿
- システム通知
- クイックアクション

### コンテンツ管理
- ポートフォリオ管理: セクション別編集、プレビュー機能、公開設定
- ブログ管理: 記事一覧（ステータス別）、カテゴリ・タグ管理、コメント管理
- メディア管理: ライブラリ、アップロード、使用状況

### 設定・ツール
- SEO設定: グローバル設定、リダイレクト管理、検索パフォーマンス
- システム設定: ユーザー管理、バックアップ、キャッシュ管理
- セキュリティ設定: 管理画面パス変更、ログイン試行回数制限、IPアドレス制限

## 11. 技術仕様
### パフォーマンス
- ページ読み込み: 3秒以内
- 画像最適化（WebP、遅延読み込み）
- CDN利用（将来）
- キャッシュ戦略

### セキュリティ
- SSL/TLS必須
- CSRF/XSS対策
- SQLインジェクション対策
- カスタム管理画面パス
- ログイン試行回数制限
- 2要素認証（将来）

### レスポンシブ・アクセシビリティ
- モバイルファースト
- タブレット最適化
- WCAG 2.1 Level AA準拠
- キーボードナビゲーション
