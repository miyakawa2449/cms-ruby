## 🔧 主要機能

### 1. 記事構成提案機能

#### 機能説明
記事のトピックを入力すると、AIが見出し構成（H2/H3レベル）を自動提案します。

#### ユースケース
1. 記事編集画面で「構成提案」セクションを開く
2. トピック入力欄に記事のテーマを入力（例: "Railsでのバックグラウンドジョブの実装方法"）
3. 「構成を提案」ボタンをクリック
4. AIが生成した見出し構成が表示される
5. 「本文に挿入」ボタンで本文エリアに挿入

#### 技術仕様
- **サービス**: `Ai::StructureSuggester`
- **モデル**: Claude 3.5 Sonnet
- **出力形式**: Markdown形式の見出し
- **生成時間**: 10秒以内

### 2. AI使用量ダッシュボード

#### 機能説明
AI機能の使用量（トークン数、リクエスト数、コスト）を可視化します。

#### 表示内容
- **サマリーカード**: 総リクエスト数、総トークン数、推定コスト
- **日別使用量グラフ**: 折れ線グラフ（Chart.js）
- **機能別使用量グラフ**: 円グラフ（Chart.js）
- **使用量ランキング**: 機能別のリクエスト数トップ5
- **使用履歴テーブル**: 詳細な使用履歴

#### フィルター機能
- 今日
- 今週
- 今月
- カスタム期間

#### エクスポート機能
- CSV形式でダウンロード
- 期間指定可能

#### 技術仕様
- **サービス**: `Ai::UsageStatisticsService`
- **グラフライブラリ**: Chart.js v4.4.0
- **データソース**: `AiUsageStat`モデル

### 3. プロンプト品質向上

#### 改善対象
1. **TitleSuggester**: より魅力的なタイトル生成
2. **SummaryGenerator**: 重要ポイントを漏らさない要約
3. **TagSuggester**: 記事内容により適合するタグ
4. **SlugGenerator**: SEO最適化されたスラッグ
5. **SeoMetaGenerator**: 魅力的なdescription
6. **StructureSuggester**: 具体的な構成提案

#### 改善方針
- システムプロンプトに「日本語で回答してください」を明記
- 出力形式の具体例を提示
- コンテキストの充実（記事内容、ターゲット読者層）
- 制約条件の明示（文字数、形式）

### 4. エラーハンドリング強化

#### リトライ機能
- 最大3回リトライ
- 指数バックオフ（1秒、2秒、4秒）
- タイムアウト: 30秒

#### エラーメッセージ
- ユーザーフレンドリーなメッセージ
- 詳細なエラーログ（サーバー側）

## 📊 データフロー

### 記事構成提案
```
ユーザー入力（トピック）
  ↓
Stimulusコントローラー
  ↓
POST /admin/ai/suggest_structure
  ↓
Admin::AiController
  ↓
Ai::StructureSuggester
  ↓
Ai::BedrockClient（リトライ機能）
  ↓
Amazon Bedrock API
  ↓
レスポンス（構成）
  ↓
Ai::UsageTracker（使用量記録）
  ↓
AiGeneration, AiUsageStat
```

### AI使用統計
```
ユーザーリクエスト（期間指定）
  ↓
GET /admin/ai_usage
  ↓
Admin::AiUsageController
  ↓
Ai::UsageStatisticsService
  ↓
AiUsageStat（集計）
  ↓
レスポンス（統計データ）
  ↓
Chart.js（グラフ描画）
```
