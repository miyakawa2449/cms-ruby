# ポートフォリオサイト仕様書

## 1. プロジェクト概要

### 1.1 目的
シニアエンジニアの技術発信・ポートフォリオサイトをCMS化し、技術ブログ機能を搭載する

### 1.2 技術スタック
- **言語**: Ruby 3.4.0（2024年12月25日リリース）
- **フレームワーク**: Ruby on Rails 8.0.1
- **CSSフレームワーク**: Tailwind CSS
- **データベース**: PostgreSQL
- **インフラ**: AWS Lightsail
- **Webサーバー**: Nginx（構築済み）
- **ドメイン**: https://miyakawa.code（SSL未設定）
- **外部API**: OpenAI API（ChatGPT）
- **バックグラウンドジョブ**: Sidekiq（AI処理用）
- **開発環境**: Docker Desktop（Mac環境）

### 1.3 サイトオーナー情報
- システムエンジニア・プロジェクトマネージャとして20年以上の経験
- 開発上流工程の専門家
- 要件定義からプログラミングまで一貫して対応可能
- 技術的な取り組みや研究を発信

## 3. 機能仕様

### 3.1 お問い合わせ・通知機能

#### 3.1.1 お問い合わせフォーム機能
- **基本機能**
  - Webフォームでの問い合わせ受付
  - 入力項目: 名前、メールアドレス、件名、メッセージ
  - バリデーション（必須項目チェック、メール形式確認）
  - スパム対策（reCAPTCHA連携）

- **通知システム**
  - メール送信（従来の仕組み）
  - Slack Webhook連携（リアルタイム通知）
  - 管理画面での問い合わせ履歴確認

#### 3.1.2 Slack連携仕様
- **通知内容**
  - お問い合わせ者情報（名前、メールアドレス）
  - 件名とメッセージのプレビュー
  - 受付日時
  - 管理画面への直接リンク

- **設定項目**
  - Slack Webhook URL（管理画面で設定）
  - 通知チャンネル指定
  - 通知のON/OFF切り替え

- **実装例**
```ruby
# app/services/slack_notifier.rb
class SlackNotifier
  def initialize(contact)
    @contact = contact
    @webhook_url = Setting.slack_webhook_url
  end

  def send_notification
    return unless @webhook_url.present?
    
    payload = {
      text: "🔔 新しいお問い合わせ",
      attachments: [
        {
          color: "good",
          fields: [
            { title: "👤 お名前", value: @contact.name, short: true },
            { title: "📧 メール", value: @contact.email, short: true },
            { title: "📋 件名", value: @contact.subject, short: false },
            { title: "💬 メッセージ", value: @contact.message.truncate(100), short: false }
          ],
          footer: "受付日時: #{@contact.created_at.strftime('%Y-%m-%d %H:%M')}"
        }
      ]
    }

    Net::HTTP.post_form(URI(@webhook_url), payload: payload.to_json)
  end
end
```
