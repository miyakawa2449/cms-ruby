# ポートフォリオサイト仕様書

## 1. プロジェクト概要

### 1.1 目的
シニアエンジニアの技術発信・ポートフォリオサイトをCMS化し、技術ブログ機能を搭載する

### 1.2 技術スタック
- **言語**: Ruby 3.4.0（2024年12月25日リリース）
- **フレームワーク**: Ruby on Rails 8.0.1（API機能含む）
- **API設計**: RESTful API（/api/v1、/api/internal）
- **認証**: Devise（管理画面）+ JWT（API）
- **CSSフレームワーク**: Tailwind CSS
- **データベース**: PostgreSQL（全文検索・JSONB活用）
- **キャッシュ**: Redis（API・セッション・Sidekiq）
- **インフラ**: AWS Lightsail
- **Webサーバー**: Nginx（構築済み）
- **ドメイン**: https://miyakawa.code（SSL未設定）
- **外部API**: OpenAI API（ChatGPT）・Slack Webhook・SNS API
- **バックグラウンドジョブ**: Sidekiq（AI処理・メール送信）
- **API セキュリティ**: Rack::Attack（レート制限）・CORS・入力検証
- **開発環境**: Docker Desktop（Mac環境）

### 1.3 サイトオーナー情報
- システムエンジニア・プロジェクトマネージャとして20年以上の経験
- 開発上流工程の専門家
- 要件定義からプログラミングまで一貫して対応可能
- 技術的な取り組みや研究を発信

#### 1.3.1 キャリア3段階構成
**独自の価値提案: 30年間の3フェーズキャリア**

1. **第1フェーズ: パソコンスクール講師時代 (1994-2005)**
   - 人材育成・プロジェクト管理基礎力の形成
   - 20名規模クラス運営による統率力・課題解決力習得
   - 情報処理国家試験指導経験

2. **第2フェーズ: SE/PM・ビジネス分析者時代 (2005-2021)**

   - ビジネス要件分析・設計文書化・チーム管理
   - 多様なステークホルダー調整・プロジェクト推進

3. **第3フェーズ: AI活用エンジニア時代 (2022-現在)**
   - ChatGPT登場を機に50代でプログラミング本格開始

## 3. 機能仕様

### 3.1 お問い合わせ・通知機能

#### 3.1.1 お問い合わせフォーム機能
- **基本機能**
  - Webフォームでの問い合わせ受付
  - 入力項目: 名前、メールアドレス、件名、メッセージ
  - バリデーション（必須項目チェック、メール形式確認）
  - スパム対策（reCAPTCHA連携）

- **通知システム**
  - メール送信（従来の仕組み）
  - Slack Webhook連携（リアルタイム通知）
  - 管理画面での問い合わせ履歴確認

#### 3.1.2 Slack連携仕様
- **通知内容**
  - お問い合わせ者情報（名前、メールアドレス）
  - 件名とメッセージのプレビュー
  - 受付日時
  - 管理画面への直接リンク

- **設定項目**
  - Slack Webhook URL（管理画面で設定）
  - 通知チャンネル指定
  - 通知のON/OFF切り替え

- **実装例**
```ruby
# app/services/slack_notifier.rb
class SlackNotifier
  def initialize(contact)
    @contact = contact
    @webhook_url = Setting.slack_webhook_url
  end

  def send_notification
    return unless @webhook_url.present?
    
    payload = {
      text: "🔔 新しいお問い合わせ",
      attachments: [
        {
          color: "good",
          fields: [
            { title: "👤 お名前", value: @contact.name, short: true },
            { title: "📧 メール", value: @contact.email, short: true },
            { title: "📋 件名", value: @contact.subject, short: false },
            { title: "💬 メッセージ", value: @contact.message.truncate(100), short: false }
          ],
          footer: "受付日時: #{@contact.created_at.strftime('%Y-%m-%d %H:%M')}"
        }
      ]
    }

    Net::HTTP.post_form(URI(@webhook_url), payload: payload.to_json)
  end
end
```
