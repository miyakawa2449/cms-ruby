## 🏁 プロジェクト概要

### 基本情報
- **目的**: シニアエンジニアの技術発信・ポートフォリオサイトのCMS化
- **技術スタック**: Ruby 3.4.7 + Rails 8.1.1 + PostgreSQL + Redis + Sidekiq 8.0.10
- **開発方式**: アジャイル開発（2週間スプリント・11スプリント構成）
- **インフラ**: AWS Lightsail

### 主要機能
1. **ポートフォリオCMS**: 8セクション構成の縦スクロール型
2. **技術ブログ**: Markdown + カテゴリ階層 + 検索
3. **メディアライブラリ**: 画像管理・最適化
4. **SEO/AEO**: 自動最適化 + AI連携
5. **管理画面**: セキュリティ強化
