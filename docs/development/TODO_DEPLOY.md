# デプロイ前検討事項

## 🔍 検索機能の設計見直し

### 現状の問題
- **ポートフォリオページの検索**: 実装したが動作していない
- **ユーザビリティ**: トップページでブログ記事検索の必要性が不明確

### 検討事項
1. **ポートフォリオページの検索機能の必要性**
   - ユーザーがトップページで記事検索する場面は限定的
   - ポートフォリオは自己紹介・実績紹介が主目的
   - ブログ検索は専用ブログページ（/blog）で十分な可能性

2. **UX設計の観点**
   - トップページ検索 → 全体サイト内検索（セクション含む）
   - ブログページ検索 → 記事専用検索
   - 目的の明確な分離が必要

3. **実装選択肢**
   - **選択肢A**: トップページ検索を削除
   - **選択肢B**: 全体サイト検索に変更（セクション+記事）
   - **選択肢C**: 現状維持（記事のみ検索）

### 推奨案
**選択肢A**: トップページの検索機能削除
- **理由**: ポートフォリオサイトの主目的に集中
- **メリット**: シンプルなUI、迷いのないナビゲーション
- **代替**: ヘッダーナビで/blogページへの誘導強化

### 実装予定
- デプロイ前にユーザビリティテストで判断
- 必要に応じて検索機能の削除または改修
