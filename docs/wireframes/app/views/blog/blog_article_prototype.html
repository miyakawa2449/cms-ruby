ChatGPT APIとRailsで作る自動記事要約システム

なぜ記事要約システムが必要なのか

SE/PMとして多くの技術資料を読む中で、「記事の要約を自動化できないか」という課題を常に感じていました。特に最新技術のキャッチアップでは、大量の記事を効率的に処理する必要があります。

16年間のPM経験で学んだこと：「情報収集の効率化は、プロジェクト成功の鍵」

今回のシステムは以下の課題を解決することを目的としています：

  • 長文記事の読解時間短縮
  • 重要ポイントの抽出自動化
  • チーム間での情報共有効率化
  • 技術トレンドの継続的な監視

要件定義：SE/PM視点での設計

パソコンスクール講師時代から培った「課題の明確化」スキルを活かし、まずは要件を整理しました：

  1. 基本機能

モデル設計

要約システムの中核となるモデルを設計します：

# app/models/article.rb
class Article < ApplicationRecord
  validates :url, presence: true, uniqueness: true
  validates :title, presence: true
  validates :original_content, presence: true
  
  has_many :summaries, dependent: :destroy
  
  enum status: { pending: 0, processing: 1, completed: 2, failed: 3 }
  
  scope :recent, -> { order(created_at: :desc) }
  scope :by_category, ->(category) { where(category: category) }
end

# app/models/summary.rb  
class Summary < ApplicationRecord
  belongs_to :article
  
  validates :content, presence: true
  validates :summary_type, presence: true
  validates :tokens_used, presence: true, numericality: { greater_than: 0 }
  
  enum summary_type: { brief: 0, detailed: 1, key_points: 2 }
end

ChatGPT API連携の実装

OpenAI APIとの連携部分を実装します。PM経験で培ったリスク管理の観点から、エラーハンドリングとリトライ処理を重視しています。

APIサービスクラスの実装

# app/services/openai_service.rb
class OpenaiService
  include HTTParty
  
  base_uri 'https://api.openai.com/v1'
  
  def initialize(api_key = nil)
    @api_key = api_key || Rails.application.credentials.openai_api_key
    @headers = {
      'Authorization' => "Bearer #{@api_key}",
      'Content-Type' => 'application/json'
    }
  end
  
  def summarize_article(content, summary_type: 'brief')
    prompt = build_prompt(content, summary_type)
    
    response = self.class.post('/chat/completions', {
      headers: @headers,
      body: {
        model: 'gpt-4',
        messages: [
          {
            role: 'system',
            content: 'あなたは技術記事の要約を作成する専門家です。'
          },
          {
            role: 'user', 
            content: prompt
          }
        ],
        max_tokens: token_limit_for(summary_type),
        temperature: 0.3
      }.to_json
    })
    
    handle_response(response)
  rescue => e
    Rails.logger.error "OpenAI API Error: #{e.message}"
    { error: e.message }
  end
  
  private
  
  def build_prompt(content, summary_type)
    case summary_type
    when 'brief'
      "以下の技術記事を3行で要約してください：\n\n#{content}"
    when 'detailed'
      "以下の技術記事の詳細な要約を作成してください。重要なポイントと実装のコツを含めてください：\n\n#{content}"
    when 'key_points'
      "以下の技術記事から重要なポイントを箇条書きで抽出してください：\n\n#{content}"
    end
  end
  
  def token_limit_for(summary_type)
    case summary_type
    when 'brief' then 150
    when 'detailed' then 500  
    when 'key_points' then 300
    end
  end
  
  def handle_response(response)
    if response.success?
      content = response.parsed_response.dig('choices', 0, 'message', 'content')
      tokens = response.parsed_response.dig('usage', 'total_tokens')
      
      {
        summary: content,
        tokens_used: tokens,
        success: true
      }
    else
      {
        error: response.parsed_response['error']['message'],
        success: false  
      }
    end
  end
end

非同期処理の実装

記事要約は時間がかかる処理なので、Sidekiqを使った非同期処理で実装します：

# app/jobs/article_summarizer_job.rb
class ArticleSummarizerJob < ApplicationJob
  queue_as :default
  
  retry_on StandardError, wait: :polynomially_longer, attempts: 3
  
  def perform(article_id, summary_type = 'brief')
    article = Article.find(article_id)
    article.update!(status: :processing)
    
    openai_service = OpenaiService.new
    result = openai_service.summarize_article(article.original_content, summary_type: summary_type)
    
    if result[:success]
      Summary.create!(
        article: article,
        content: result[:summary],
        summary_type: summary_type,
        tokens_used: result[:tokens_used]
      )
      article.update!(status: :completed)
      
      # Slack通知（オプション）
      notify_completion(article)
    else
      article.update!(status: :failed, error_message: result[:error])
      Rails.logger.error "Summarization failed for article #{article_id}: #{result[:error]}"
    end
  end
  
  private

  end
end

# app/controllers/articles_controller.rb
class ArticlesController < ApplicationController
  before_action :set_article, only: [:show, :destroy]
  
  def index
    @articles = Article.recent
                      .includes(:summaries)
                      .page(params[:page])
                      .per(10)
    
    @articles = @articles.by_category(params[:category]) if params[:category].present?
  end
  
  def show
    @summaries = @article.summaries.order(:created_at)
  end
  
  def create
    @article = Article.new(article_params)
    
    if @article.save
      # 記事内容の取得
      fetch_article_content(@article)
      
      # 非同期で要約生成開始
      ArticleSummarizerJob.perform_later(@article.id, params[:summary_type] || 'brief')
      
      render json: { 
        status: 'success', 
        message: '要約処理を開始しました',
        article_id: @article.id 
      }
    else
      render json: { 
        status: 'error', 
        errors: @article.errors.full_messages 
      }
    end
  end
  
  private
  
  def set_article
    @article = Article.find(params[:id])

    params.require(:article).permit(:url, :category)
