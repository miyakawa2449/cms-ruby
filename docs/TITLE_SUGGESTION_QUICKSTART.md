# タイトル提案機能 クイックスタート

## 機能概要

記事の本文を分析して、2種類のタイトルを自動提案します：

1. **わかりやすいタイトル** - SEO重視、内容を正確に表現
2. **SNS映えするタイトル** - クリック率重視、感情に訴える

## 使い方（3ステップ）

### 1. 記事を作成・保存
```
管理画面 → 記事 → 新規作成
↓
タイトルと本文を入力
↓
「作成する」ボタンをクリック
```

### 2. AI提案ボタンをクリック
```
タイトルフィールドの横にある
「AI提案」ボタンをクリック
```

### 3. タイトルを選択
```
表示された候補から
気に入ったタイトルをクリック
↓
自動的にタイトルフィールドに反映
```

## 動作確認

### 1. ルーティング確認
```bash
rails routes | grep suggest_title
```

期待される出力：
```
admin_article_ai_suggest_title POST /admin-secure-panel-miyakawa2449/articles/:article_id/ai/suggest_title
```

### 2. テスト実行
```bash
bundle exec rspec spec/services/ai/title_suggester_spec.rb
bundle exec rspec spec/requests/admin/ai_controller_spec.rb
```

### 3. 手動テスト
1. 開発サーバー起動: `bin/dev`
2. 管理画面にログイン
3. 記事を作成・保存
4. 「AI提案」ボタンをクリック
5. タイトル候補が表示されることを確認

## トラブルシューティング

### ボタンが表示されない
- 記事を保存していますか？（新規作成時は保存後に表示）
- JavaScriptコンソールにエラーはありませんか？

### 「記事を保存してから...」エラー
- 記事を一度保存してから使用してください

### 「記事の本文が必要です」エラー
- 本文フィールドに内容を入力してください

### 「AI機能は現在利用できません」エラー
- AWS Bedrock の認証情報を確認してください
- `.env` ファイルに以下の設定があるか確認：
  ```
  AWS_BEDROCK_REGION=us-east-1
  AWS_BEDROCK_ACCESS_KEY_ID=your_key
  AWS_BEDROCK_SECRET_ACCESS_KEY=your_secret
  ```
