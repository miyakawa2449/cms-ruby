# AI Roles and Responsibilities

このプロジェクトでは、3つのAIが明確な役割分担で協働します。

## 役割定義

### Claude Code
**担当**: 実装
- 新規機能の開発
- リファクタリング作業
- コードの記述・修正

### Kiro
**担当**: 仕様管理
- 設計レビュー
- 受け入れ判断
- 仕様の整合性確認

### Codex
**担当**: デバッグ
- テスト失敗時の原因切り分け
- 安全な削除・変更の判断
- 検証ログの記録
- 再現手順の文書化

## 実績

Codex は過去のリファクタリング作業において、全てのエラーを安全に取り除いた実績があり、デバッグ担当として信頼できることが証明されています。

## 協働フロー

1. **仕様策定**: Kiro が設計をレビュー・承認
2. **実装**: Claude Code が機能を実装
3. **デバッグ**: Codex がテスト・検証・問題解決
4. **受け入れ**: Kiro が最終判断

各AIは自身の役割に専念し、専門性を活かして効率的に作業を進めます。

## 重要な原則

**AI は自分の役割を越えた判断が必要な場合、必ず人に確認する。**

- Claude Code: 仕様の解釈が曖昧な場合、実装方針の判断が必要な場合
- Kiro: 要件定義の変更が必要な場合、優先順位の判断が必要な場合
- Codex: 安全性の判断が困難な場合、大規模な変更が必要な場合
