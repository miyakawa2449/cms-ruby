## 🔧 機能要件

### FR-5.7.1: AI機能テスト

#### 1.1 各Suggesterのユニットテスト
- **対象サービス**:
  - TitleSuggester
  - SummaryGenerator
  - TagSuggester
  - SlugGenerator
  - SeoMetaGenerator
  - StructureSuggester

- **テスト項目**:
  - プロンプト生成の正確性
  - レスポンスパースの正確性
  - エラーハンドリング
  - モック使用（外部API依存排除）

#### 1.2 BedrockClientのモックテスト
- **テスト項目**:
  - 正常系（成功レスポンス）
  - 異常系（タイムアウト、APIエラー）
  - リトライ機能
  - エラーログ出力

### FR-5.7.2: 統合テスト強化

#### 2.1 記事CRUD全フローテスト
- **テストシナリオ**:
  1. 記事作成 → AI機能使用 → 保存
  2. 記事編集 → カテゴリ/タグ変更 → 更新
  3. 記事削除 → キャッシュ無効化確認
  4. 記事公開 → フロントエンド表示確認

#### 2.2 認証・認可テスト
- **テスト項目**:
  - ログイン・ログアウト
  - 非認証ユーザーのアクセス拒否
  - セッション管理
  - CSRF保護

### FR-5.7.3: E2Eテスト導入

#### 3.1 Capybara + Selenium設定
- **設定内容**:
  - Capybara gemのインストール
  - Selenium WebDriverの設定
  - ヘッドレスChrome設定
  - スクリーンショット機能

#### 3.2 主要フローのE2Eテスト
- **対象フロー**:
  - 記事作成フロー（ログイン → 記事作成 → AI機能使用 → 保存 → 確認）
  - 画像アップロードフロー（画像選択 → トリミング → アップロード → 確認）
  - メディアライブラリフロー（画像一覧 → 編集 → 保存 → 確認）
