## 追加実装: デフォルトユーザー保持機能 ✅

### 背景

レビュー中に発見された問題:
- インポート時に全AdminUserが削除される
- 開発環境のデフォルトユーザー（admin@portfolio.dev）も消える
- エクスポート元のAdminUserでしかログインできない

### 実装内容

**DatabaseImportService に `ensure_default_admin_user` メソッドを追加**

```ruby
def ensure_default_admin_user
  default_email = "admin@portfolio.dev"

  unless AdminUser.exists?(email: default_email)
    AdminUser.create!(
      email: default_email,
      password: DEFAULT_PASSWORD,
      password_confirmation: DEFAULT_PASSWORD
    )
    Rails.logger.info "[DatabaseImport] Created default admin user: #{default_email}"
  else
    Rails.logger.info "[DatabaseImport] Default admin user already exists: #{default_email}"
  end
end
```

### 動作

#### 開発/テスト環境
- インポート後、`admin@portfolio.dev` を自動作成
- パスワードは `password123`
- `db:seed` を再実行する必要なし

#### 本番環境
- デフォルトユーザーは作成されない
- エクスポート元のAdminUserのみ

### テスト更新

- AdminUser のカウント期待値を調整（1 → 2）
- デフォルトユーザーの存在確認を追加

### README更新

注意事項に「デフォルトユーザー」の項目を追加
