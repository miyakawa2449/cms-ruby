# Phase 5.5: AI機能改善 - 要件定義

**Phase**: 5.5  
**機能名**: AI機能改善  
**優先度**: 高  
**実施期間**: 2026-01-19 〜 2026-01-20（2日間）  
**前提条件**: Phase 5.2（AI機能実装）完了

---

## 📋 概要

Phase 5.2で実装したAI機能（Amazon Bedrock連携）の改善・拡張を行います。記事構成提案機能の有効化、AI使用量ダッシュボードの追加、プロンプト品質の向上を実施します。

---

## 🎯 目標

1. **記事構成提案機能の有効化**: 既存のStructureSuggesterサービスをUI統合
2. **AI使用量ダッシュボード**: トークン使用量・コストの可視化
3. **プロンプト品質向上**: 各サービスのプロンプト改善・日本語出力精度向上

---

## 👥 ユーザーストーリー

### US-5.5.1: 記事構成提案機能
**As a** ブログ記事執筆者  
**I want** トピックから記事の見出し構成を自動提案してもらいたい  
**So that** 記事の構成を考える時間を短縮し、執筆に集中できる

**受入基準**:
- [ ] 1.1 記事編集画面に「構成提案」ボタンが表示される
- [ ] 1.2 トピック入力欄に記事のテーマを入力できる
- [ ] 1.3 「構成提案」ボタンをクリックすると、見出し構成が生成される
- [ ] 1.4 提案された構成は、H2/H3レベルの見出しリストとして表示される
- [ ] 1.5 提案された構成を本文エリアにMarkdown形式で挿入できる
- [ ] 1.6 生成中はローディング表示が出る
- [ ] 1.7 エラー時は分かりやすいエラーメッセージが表示される

### US-5.5.2: AI使用量ダッシュボード
**As a** サイト管理者  
**I want** AI機能の使用量とコストを確認したい  
**So that** 予算管理とコスト最適化ができる

**受入基準**:
- [ ] 2.1 管理画面に「AI使用統計」ページが追加される
- [ ] 2.2 日別のトークン使用量がグラフで表示される
- [ ] 2.3 月別のトークン使用量がグラフで表示される
- [ ] 2.4 機能別（タイトル提案、要約生成等）の使用量が表示される
- [ ] 2.5 推定コスト（USD）が表示される
- [ ] 2.6 使用量の多い機能がランキング形式で表示される
- [ ] 2.7 期間フィルター（今日、今週、今月、カスタム）が使える
- [ ] 2.8 CSV形式でエクスポートできる

### US-5.5.3: プロンプト品質向上

## 🔧 機能要件

### FR-5.5.1: 記事構成提案機能

#### 1.1 StructureSuggesterサービスの有効化
- **現状**: サービスクラスは実装済みだが、UI未統合
- **実装内容**:
  - `app/services/ai/structure_suggester.rb`の動作確認
  - プロンプトの改善（より具体的な構成提案）
  - エラーハンドリングの強化

#### 1.2 UI統合
- **実装場所**: `app/views/admin/articles/_form.html.erb`
- **実装内容**:
  - 「構成提案」セクションの追加
  - トピック入力欄（textarea）
  - 「構成提案」ボタン
  - 提案結果表示エリア
  - 「本文に挿入」ボタン

#### 1.3 Stimulusコントローラー拡張
- **実装場所**: `app/javascript/controllers/ai_assistant_controller.js`
- **実装内容**:
  - `suggestStructure()`メソッドの追加
  - トピック取得・バリデーション
  - API呼び出し（`/admin/ai/suggest_structure`）
  - 結果表示・本文挿入機能

#### 1.4 APIエンドポイント追加
- **実装場所**: `app/controllers/admin/ai_controller.rb`
- **実装内容**:
  - `suggest_structure`アクション
  - パラメータ: `topic`（必須）
  - レスポンス: `{ structure: "## 見出し1\n### 小見出し1-1\n..." }`

### FR-5.5.2: AI使用量ダッシュボード

#### 2.1 統計ページの作成
- **実装場所**: `app/views/admin/ai_usage/index.html.erb`
- **実装内容**:
  - ページタイトル「AI使用統計」
  - 期間フィルター（今日、今週、今月、カスタム）
  - サマリーカード（総トークン数、推定コスト、総リクエスト数）
  - 日別使用量グラフ（Chart.js）
  - 機能別使用量グラフ（円グラフ）
  - 使用履歴テーブル（ページネーション付き）

#### 2.2 統計サービスの実装
- **実装場所**: `app/services/ai/usage_statistics_service.rb`
- **実装内容**:
  - `daily_usage(start_date, end_date)`: 日別使用量
  - `monthly_usage(year, month)`: 月別使用量
  - `usage_by_feature(start_date, end_date)`: 機能別使用量
  - `total_cost(start_date, end_date)`: 推定コスト計算
  - `top_features(limit)`: 使用量ランキング

#### 2.3 コントローラーの実装
- **実装場所**: `app/controllers/admin/ai_usage_controller.rb`
- **実装内容**:
  - `index`アクション: 統計ページ表示
  - `export`アクション: CSV形式でエクスポート
  - 期間フィルター処理

#### 2.4 ルーティング追加
```ruby
namespace :admin do
  resources :ai_usage, only: [:index] do
    collection do
      get :export
    end
  end
end
```

### FR-5.5.3: プロンプト品質向上

#### 3.1 各サービスのプロンプト改善
- **対象サービス**:
  1. `TitleSuggester`: より魅力的なタイトル生成
  2. `SummaryGenerator`: 重要ポイントを漏らさない要約
  3. `TagSuggester`: 記事内容により適合するタグ
  4. `SlugGenerator`: SEO最適化されたスラッグ
  5. `SeoMetaGenerator`: 魅力的なdescription
  6. `StructureSuggester`: 具体的な構成提案

#### 3.2 プロンプト改善の方針
- **日本語出力の精度向上**:
  - システムプロンプトに「日本語で回答してください」を明記
  - 出力形式の具体例を提示
  - 文体の統一（です・ます調）

- **コンテキストの充実**:
  - 記事の既存内容を考慮
  - ターゲット読者層の明示
  - ブログのトーン&マナーの指定

- **出力品質の向上**:
  - 具体的な指示（「〜を含めてください」）
  - 制約条件の明示（文字数、形式）
  - 良い例・悪い例の提示

#### 3.3 エラーハンドリング強化
- **実装場所**: `app/services/ai/bedrock_client.rb`
- **実装内容**:
  - リトライ機能（最大3回、指数バックオフ）
  - タイムアウト設定（30秒）
  - エラーログの詳細化
  - ユーザーフレンドリーなエラーメッセージ

## 🚫 非機能要件

### NFR-5.5.1: パフォーマンス
- AI使用量ダッシュボードのグラフ描画は3秒以内
- 統計データのクエリは1秒以内
- 記事構成提案は10秒以内に完了

### NFR-5.5.2: セキュリティ
- AI使用統計ページは管理者のみアクセス可能
- CSVエクスポートは認証必須
- APIエンドポイントはCSRF保護

### NFR-5.5.3: 保守性
- プロンプトは定数として管理（変更容易）
- 統計サービスはテスト可能な設計
- グラフライブラリ（Chart.js）のバージョン固定

### NFR-5.5.4: 可用性
- AI APIエラー時もアプリケーションは正常動作
- 統計データが存在しない場合も適切に表示
- グラフ描画エラー時はテーブル表示にフォールバック

## 📊 データモデル

### AiGeneration（既存モデル - 変更なし）
```ruby
# 既存のカラム
- feature_type: string        # 機能タイプ（title, summary, tags等）
- prompt: text                # 送信したプロンプト
- response: text              # AIの応答
- model_name: string          # 使用モデル
- input_tokens: integer       # 入力トークン数
- output_tokens: integer      # 出力トークン数
- cost_usd: decimal(10, 6)    # コスト（USD）
- article_id: integer         # 関連記事ID（nullable）
- created_at: datetime
```

### AiUsageStat（既存モデル - 変更なし）
```ruby
# 既存のカラム
- date: date                  # 集計日
- feature_type: string        # 機能タイプ
- model_name: string          # モデル名
- request_count: integer      # リクエスト数
- total_input_tokens: integer # 総入力トークン数
- total_output_tokens: integer# 総出力トークン数
- total_cost_usd: decimal(10, 6) # 総コスト
- created_at: datetime
- updated_at: datetime
```
