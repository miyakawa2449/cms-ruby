## 🏗️ アーキテクチャレビュー

### データモデル

#### MediaMetadata モデル ✅

**仕様書との比較**:
```ruby
# 仕様書
create_table :media_metadata do |t|
  t.references :attachment, foreign_key: { to_table: :active_storage_attachments }
  t.string :alt_text
  t.integer :width
  t.integer :height
  t.string :mime_type
  t.integer :file_size
  t.jsonb :variants, default: {}
  t.integer :usage_count, default: 0
  t.timestamps
end

# 実装
create_table :media_metadata do |t|
  t.references :blob, foreign_key: { to_table: :active_storage_blobs }  # ⚠️ 差異
  t.string :alt_text
  t.integer :width
  t.integer :height
  t.string :mime_type
  t.bigint :file_size  # ⚠️ bigint（より適切）
  t.jsonb :variants, default: {}
  t.integer :usage_count, default: 0
  t.timestamps
end
```

**評価**: 🟢 実装の方が優れている
**理由**: 
- `attachment`ではなく`blob`を直接参照する方がシンプル
- `file_size`を`bigint`にすることで大容量ファイルに対応
