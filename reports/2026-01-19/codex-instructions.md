## ⚠️ 注意事項

### 既知の未実装機能

以下の機能は未実装のため、関連するテストは失敗する可能性があります：

1. **フラグメントキャッシュ**: ビューに`<% cache %>`ブロックがない
2. **Redisキャッシュストア**: Solid Cacheを使用中
3. **Redisセッションストア**: Cookie Storeを使用中
4. **rack-mini-profiler設定**: initializerファイルがない

これらは**テストの失敗として記録**し、レポートに含めてください。

### テスト環境の準備

```bash
# テストデータベースのセットアップ
bundle exec rails db:test:prepare

# テストデータの作成（必要に応じて）
bundle exec rails db:seed RAILS_ENV=test

# Redisの起動確認
docker-compose up -d redis
```

### テスト実行コマンド

```bash
# 全テスト実行
bundle exec rspec

# ユニットテストのみ
bundle exec rspec spec/models spec/services spec/helpers

# パフォーマンステストのみ
bundle exec rspec spec/performance

# 特定のファイルのみ
bundle exec rspec spec/models/concerns/cache_sweeper_spec.rb
```
