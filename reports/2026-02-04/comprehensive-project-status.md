## 🚀 Phase 7.3: 自動バックアップシステム（次の実装推奨）

### 仕様書作成状況: ✅ 完成（2026-02-04）

**ドキュメント**:
- `.kiro/specs/phase-7.3-auto-backup/requirements.md` - 13の要件定義
- `.kiro/specs/phase-7.3-auto-backup/design.md` - アーキテクチャ、9コンポーネント、22プロパティ
- `.kiro/specs/phase-7.3-auto-backup/tasks.md` - 21タスク、47サブタスク、22テストタスク

### 主要機能

#### バックアップ対象
1. **PostgreSQL全テーブル**: pg_dump -Fc形式 + gzip圧縮
2. **Active Storage**: storage/ディレクトリ全体（tar.gz）
3. **設定ファイル**: .env, config/credentials.yml.enc, config/master.key

#### 保存先・暗号化
- **AWS S3バケット**: `portfolio-backup-miyakawa2449`
- **リージョン**: `ap-northeast-1`（東京）
- **暗号化**: AES-256（SSE-S3）
- **オブジェクトキー形式**: `{backup_type}/{YYYY}/{MM}/{DD}/{category}_{filename}`

#### 世代管理
- **日次バックアップ**: 7日間保持（毎日午前3時）
- **週次バックアップ**: 4週間保持（毎週日曜日午前3時）
- **月次バックアップ**: 12ヶ月保持（毎月1日午前3時）

#### 復元機能
- 管理画面からのワンクリック復元
- バックアップ一覧表示（日時、タイプ、ファイルサイズ）
- 復元前の確認ダイアログ
- 復元ログ記録

#### 通知機能（Phase 7.8統合）
- バックアップ成功/失敗のメール通知
- Slack通知（オプション）
- BackupMailer使用（Phase 7.8で実装済み）

### コスト見積もり

**前提条件**:
- データベースサイズ: 100MB（圧縮後）
- Active Storageサイズ: 500MB（圧縮後）
- 設定ファイルサイズ: 1MB（圧縮後）
- 合計バックアップサイズ: 601MB

**世代管理後の合計ストレージ**: 13.8GB
- 日次: 7世代 × 601MB = 4.2GB
- 週次: 4世代 × 601MB = 2.4GB
- 月次: 12世代 × 601MB = 7.2GB

**月額コスト**:

- データ転送: 約7円/月（月1回復元テスト）
- リクエスト: 約0.05円/月
- **合計**: 約63円/月

### 実装開始手順

#### 1. AWS S3セットアップ（実装前に必須）

**S3バケット作成**:
```
バケット名: portfolio-backup-miyakawa2449
リージョン: ap-northeast-1（東京）
暗号化: SSE-S3（AES-256）
パブリックアクセス: 全てブロック
バージョニング: 有効
```

**IAMユーザー作成**:
```
ユーザー名: portfolio-backup-user
ポリシー: カスタムポリシー（最小権限）
  - s3:PutObject
  - s3:GetObject
  - s3:DeleteObject
  - s3:ListBucket
対象リソース: arn:aws:s3:::portfolio-backup-miyakawa2449/*
```

**環境変数設定**:
```bash
AWS_ACCESS_KEY_ID=your_access_key_id
AWS_SECRET_ACCESS_KEY=your_secret_access_key
AWS_REGION=ap-northeast-1
S3_BACKUP_BUCKET=portfolio-backup-miyakawa2449
```
