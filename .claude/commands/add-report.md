---
description: 作業報告書を自動生成
---

作業報告書を生成してください：

1. 現在の日付で `/reports/YYYY-MM-DD/` ディレクトリを作成（なければ）
2. 連番ファイル名を決定（1st.md, 2nd.md, 3rd.md, ...）
3. 以下のテンプレートで報告書を作成：

```markdown
# 作業報告 - $ARGUMENTS

## 基本情報
- **日時**: [現在日時]
- **ブランチ**: [git branch --show-current]
- **最新コミット**: [git log --oneline -1]

## 完了タスク
- [ ]

## 実装内容
### 変更ファイル
[git diff --name-only で取得]

### 技術的な判断・決定事項


## 発生した課題と解決策


## 次回申し送り事項

```

4. ユーザーに内容を確認してもらい、必要に応じて編集
